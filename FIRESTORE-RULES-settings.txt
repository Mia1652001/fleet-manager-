FIRESTORE RULES — add this before you use the Settings page
===========================================================

The Settings page writes to a NEW collection called `settings`. Until the rules
below are published, saving on that page will fail with a permission error. This
is the usual step whenever a new collection is added.

WHERE TO PUT IT
---------------
1. Go to console.firebase.google.com and sign in.
2. Pick the project car-rental-system-2a93b.
3. In the left sidebar click "Build", then "Firestore Database".
4. Along the top of the panel click the "Rules" tab.
5. You will see a block that starts with `rules_version` and contains several
   `match /...` sections, one per collection (cars, bookings, customers, tasks).
6. Add the block below as one more `match` section, alongside the others and
   INSIDE the outer `match /databases/{database}/documents {` braces.
7. Click "Publish" at the top. It takes effect within a few seconds.


THE BLOCK TO ADD
----------------

    // Company settings — one document per company, named after the companyId.
    // Everyone signed in to the company can read it (the app needs the currency
    // and company name on every screen) and edit it. The companyId on the
    // document must match the folder name and must never change, which is the
    // same protection the other collections have.
    match /settings/{companyId} {
      function myCompany() {
        return get(/databases/$(database)/documents/users/$(request.auth.uid)).data.companyId;
      }
      allow read: if request.auth != null && companyId == myCompany();
      allow create: if request.auth != null
                    && companyId == myCompany()
                    && request.resource.data.companyId == companyId;
      allow update: if request.auth != null
                    && companyId == myCompany()
                    && request.resource.data.companyId == resource.data.companyId;
      allow delete: if false;   // settings are edited, never deleted
    }


HOW TO CHECK IT WORKED
----------------------
Open the app, go to Settings, type the company name and press
"Save company details". If you see "Saved." it is working. If you see a message
about permissions, the rules have not published yet — wait a few seconds and try
again, or re-check that the block sits inside the outer braces.


A NOTE ON THE LOGO
------------------
The logo is stored as text inside this same document, because image storage
needs the paid Blaze plan. The app shrinks any image to 320px in the browser
before saving, which keeps it far below the 1MB limit a Firestore document has.
Nothing else needs changing for it to work.
